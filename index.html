⚠️ Database Setup Needed in Firebase Console

Open your Firebase Console → Build → Firestore Database, ensure the database is created, and set the Rules tab to:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
