⚠️ Database Write Blocked by Firebase Rules

Go to your Firebase Console → Firestore Database → Rules tab and make sure your rules allow read/write access, then click Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
